# Random Users App

A React app that fetches and displays user profiles from the FreeAPI.

## Live Demo
https://react-project-cohort-2026.vercel.app/

## Tech Stack
- React
- Tailwind CSS
- Vite
- FreeAPI

## Run Locally

```bash
npm install
npm run dev
```

## API Used
https://api.freeapi.app/api/v1/public/randomusers
