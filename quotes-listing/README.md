# Quotes Listing Application

A quotes browsing app built with React and Tailwind CSS using FreeAPI.

## What it does
Fetches and displays quotes with author name, tags, and date. 30 pages, 300 total quotes.

## Tech Stack
- React 18
- Tailwind CSS
- Vite
- FreeAPI

## Run Locally
```bash
npm install
```
