# Meals Listing Interface

A clean and responsive meals listing app built with React and Tailwind CSS using the FreeAPI Meals endpoint.

## What it does
Fetches and displays meal data from FreeAPI including meal name, image, category, cuisine, tags, instructions preview, YouTube recipe link, and full recipe source.

## Tech Stack
- React 18
- Tailwind CSS
- Vite
- FreeAPI

## Run Locally

```bash
npm install
npm run dev
```
