# Random Cat Viewer

    A random cat viewer app built with React and Tailwind CSS using FreeAPI.

## Live Demo
https://react-project-cohort-2026-4fc9.vercel.app/
## GitHub
https://github.com/iamdipanshugupta/React-Project-Cohort-2026/tree/main/random-cat
## What it does
Fetches and displays a random cat with breed info, stats, and Wikipedia link. Click "Next Cat" for a new one.

## Tech Stack
- React 18
- Tailwind CSS
- Vite
- FreeAPI

## Run Locally
```bash
npm install
npm run dev
```

## API
```
GET https://api.freeapi.app/api/v1/public/cats/cat/random
```
